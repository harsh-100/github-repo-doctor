# Repo Doctor reports: sample-project

- `index.html`: history of all analyses of this project (open it in a browser)
- `project.json`: project identity and run list
- `runs/<run-id>/`: one folder per analysis, never overwritten:
  `report.html` and `report.md` (same content), `findings.json` (the data both are built from),
  `metadata.json` (run summary) and `assets/` (charts)
